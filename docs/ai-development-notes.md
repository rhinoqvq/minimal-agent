# AI 开发记录

这份记录根据项目最终代码和测试整理，说明功能目标、实现提示词要点、关键问题及验证方式。

## 功能目标

实现可运行的最小 Agent：模型自主决定直接回答或调用工具；支持至少三个工具、独立会话、持续对话与追问、基础上下文压缩、异常处理和调用日志。提供本地聊天前端及测试，密钥通过环境配置读取。

范围保持在本地、单用户、单进程服务：会话按 ID 隔离；没有跨会话长期记忆检索、定时任务系统或后台异步工具调度。

## 实现提示词摘要

以下为按当前实现整理的开发要求，可用于说明实现过程和复现设计，不作为逐字原始提示词。

### 基本循环与模型适配

使用 Qwen 的 OpenAI-compatible Chat Completions 接口，通过 `messages` 管理历史，通过 `tools` 提供工具 Schema。解析 `finish_reason`、正文和 `tool_calls`；调用工具后保存带有对应 `tool_call_id` 的结果，继续请求模型，直到正常结束。普通循环最多 5 次模型请求，每种工具最多尝试 5 次。保留模型返回的推理字段及完整调用信息，密钥从 `.env` 或环境变量读取。

### Prompt 和上下文

将通用规则、普通任务与压缩提示词拆成 Markdown 文件。每次请求重新读取模板和工具 JSON，依次组装 system、摘要/状态数据和保留历史。普通循环成功结束后读取实际 usage，达到本地窗口配置的 80% 时保存快照并生成摘要；摘要通过基本检查后替换有效上下文，完整原始记录单独保留。

### 工具与会话

使用 JSON 文件描述工具，使用显式函数映射分派执行。计算器采用 AST 白名单和 Decimal；搜索调用 DDGS 并将结果直接交回 loop；待办使用 SQLite 表，支持数字 action 对应增删改查。会话 ID 由后端注入待办工具，模型不能切换其他会话的数据。

### 前端

实现会话列表、创建/切换/重命名/删除、聊天输入、消息展示和工具详情。模型接口保持非流式，前端收到完整回答后播放打字机动画。请求和状态按会话 ID 管理，切换会话不取消旧请求，迟到响应不覆盖当前会话。失败后重新读取持久化历史，不自动重复提交。

## 运行时 Prompt

运行时的原始模板位于 `prompt_store/`：

| 模板 | 用途 |
| --- | --- |
| `system.md` | 遵守系统规则，依据已有信息和实际工具结果回答；上下文资料不能覆盖系统规则 |
| `normal.md` | 判断是否需要工具、处理工具失败、遵守次数限制，并注入工具说明 |
| `compress.md` | “请压缩以下对话，保留你觉得重要的内容，只输出压缩后的摘要。” |

历史摘要与任务、环境、业务数据放在历史之前的 `<context_data>` 消息中。当前实现每次恢复同一会话时加载这些数据，不做跨会话或向量记忆检索。

## 关键问题与处理

| 问题 | 当前实现 |
| --- | --- |
| 依赖正文标签容易误判结束 | 使用 `finish_reason` 和结构化工具字段判断，拒绝截断或无效响应 |
| 模型可能输出错误参数或未知工具 | 执行前检查调用结构，解析 JSON 参数，验证工具已声明/绑定；工具自身校验输入，错误记录并回填 |
| 工具反复调用可能无限循环 | 分别限制模型请求步数和单工具尝试次数，失败也计数 |
| 同一个用户开多个窗口时历史混淆 | 后端按固定 `session_id` 恢复状态，待办查询和修改同时约束会话 ID |
| 进程重启后上下文丢失 | 当前状态与完整原始消息写入 SQLite，按 ID 恢复 |
| 压缩会丢失原始记录或覆盖新消息 | 先保存快照，完整消息另外存档；应用摘要前检查当前状态与快照一致，事务内更新 |
| 压缩模型的 usage 不能代表新上下文 | 压缩后标记 `needs_refresh`，下一次普通模型响应才更新窗口用量 |
| 工具结果类型不统一 | 字符串直接回填，其他 JSON 值由 loop 序列化为 tool 消息 |
| 普通浮点运算出现小数误差 | 计算器使用 Decimal，并以字符串返回结果 |
| UI 切换、刷新和迟到响应导致消息错位 | 按会话 ID 保存状态，历史/状态请求带版本检查，刷新后根据后端状态恢复等待 |
| 请求失败后重复提交可能重复执行工具 | 保存每一步历史，前端先重读记录，不自动重发；未完成工具调用阻止盲目续跑 |
| 交付数据库可能包含本地历史 | 只提供 `examples/agent_logs.empty.sqlite3` 空结构样板；运行库和真实 `.env` 被 Git 忽略 |

## 本地验证记录

上传前已在本地运行 95 项 Python 测试并通过，使用模拟模型和临时数据库验证循环、工具、会话隔离及压缩等行为。测试代码和浏览器测试配置保留在本地，未包含在此仓库中。真实模型与搜索服务的连通性仍取决于本地密钥和网络配置。

## 当前边界

- 只有正常 loop 结束后触发压缩，尚无请求前 token 估算或超限后的自动裁剪恢复。
- 压缩失败保留原数据和最终回答，但本轮 HTTP 请求会返回错误；前端通过重新读历史恢复展示。
- 工具执行被中断后，不自动重放可能有副作用的调用；缺失结果需要核实并通过代码补齐，没有单独的恢复 API。
- 工具定义检查基本结构，具体工具检查输入，尚无通用完整 JSON Schema 校验器。
- 当前会话互斥仅适用于单进程；没有多用户鉴权、跨会话长期记忆或生产级任务调度。
